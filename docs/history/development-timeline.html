Phase D — Temperature collapse: 진단과 해결

증상: epoch 0.5~4 안정 (logit_scale 38~58) → epoch ~4.3부터 gradient 폭주 → epoch 6에 클램프 상한(scale ~1000) 고정, loss_val/ita 동반 붕괴.

분석: weight decay 기여는 ~1.5%/epoch뿐인데 관측 변동은 30~40% → 1/temp 나눗셈 구조의 1/temp² gradient 증폭이 주범. 독립 용의자 분리: ① VG region 캡션이 bbox가 아닌 전체 이미지를 쓰던 데이터 버그 (b6a0429에서 수정), ② temp 파라미터화 (원본 BLIP과 동일 — fork 탓이 아님).

Phase J — ITC 증류 진단의 계곡

기록: critical_bugfix/ 진단 문서 2건 — 기술적으로 가장 밀도 높은 구간

J-1. ×τ² 버그 (07-07): loss_itc_kd ≈ 0.0034 — 다른 loss 대비 ~2000× 작음. Hinton ×T²는 T>1(softening) 전제인데 τ=0.05<1(sharpening)이라 gradient를 오히려 죽임. KL 자체는 1.36 nats로 정상.

J-2. τ 실측 선정 (07-07): 티처 유사도 4000 pos/156k neg 측정 — pos 0.42/neg 0.31, margin 0.016(aug ON), argmax=diag 58.7%(신호 상한). τ≥0.1 즉시 균등화 → τ=0.022 선정 (pos-prob 0.46, 학생 수렴온도 0.023 앵커).

J-3. exp 6.1/6.2 완주 (07-14): 6.1(droptau, λ=1) — ep1 r_mean 40.2 (baseline 21.9, +18: 티처 신호 가치 증명) 그러나 ep20 59.5 vs 63.4 (−3.9). 6.2(keeptau2) — no-op 대조군 확인(62.7).

J-4. Phase 0 진단 (07-14): grad probe — λ=1에서 |g_kd|/|g_ita| 6.7→2.6 전 구간 압도, cos(g_kd, g_ita) 전 조합 음수(초반 순 갱신이 ITC 방향과 −0.6 정렬). 학생 기하 — margin 0.082→0.054 압축을 logit_scale 59→88 인플레가 정확히 상쇄 (margin×scale 4.84 vs 4.77 불변). Hinton crossover 실측 → 올바른 보정은 ×τ.

지표 원칙 확립 — val ITC loss는 scale 오염 지표. 런 간 비교는 rank 기반 retrieval로만.

Phase L — 두 갈래 재도전 (진행 중)

갈래 1 — Phase 1: λ 크기 정합 (dev fe23681): ×τ 보정 + 단일 공유 λ=2.5 (목표 ep0 ratio ~0.4). Arm T(τ=0.022, sharp) vs Arm S(τ=0.05, soft) — "같은 압력, 다른 sharpness". 07-14 14:26부터 두 arm 동시 가동 중 (4GPU MPS, eff 160). 게이트: ep20 r_mean ≥63.4 필수, 목표 66+.

갈래 2 — exp9: teacher-target-mix (브랜치 exp9_teacher_target_mix, 9커밋): 티처를 별도 loss가 아닌 ITC soft-target에 혼합 → grad 충돌이 정의상 소멸. target = 0.6·one-hot + 0.4·[γ·teacher + (1−γ)·momentum], γ 2ep 홀드 → ep12 선형 감쇠. variant 9.1(in_batch)/9.2(queue). 단위테스트 9/9 + 리뷰 SHIP READY, 스페어 서버 GPU 스모크 → 본런 대기.
