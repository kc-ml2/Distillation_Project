Why MiniLM has no MLM/NSP head MiniLM was trained purely on the teacher's last-layer self-attention distribution KL + value-relation KL (no MLM, no NSP). So the released checkpoint (199 tensors / 33,360,000 parameters) has no cls.* keys at all. The 45,260,348 in the conversion-time log decomposes exactly as 33,360,000 + 11,899,578 (untied MLM head) + 770 (NSP head) — they were there originally and stripped in the release.

Tokenizer identity — a byte-level proof The git blob sha1 of vocab.txt is identical across both repos: fb140275c155a9c7c5a3b3e0e77a9e839594a938 (231,508 B). A git blob sha1 is the SHA-1 of blob <size>\0<content>, so same sha1 + same size ⇒ contents are exactly identical. Thanks to this, [DEC]=30522, [ENC]=30523, and len(tokenizer)=30524 match exactly between teacher and student, and the LM-logit-distillation assert torch.equal(teacher_lm_input_ids, decoder_input_ids) is structurally always true.

The corpora, however, differ. The MiniLM release we use is not the one from paper §4.1 (BERT-base teacher · 16GB) but the §5.1 "Better Teacher Better Student" variant (UniLMv2 teacher · 160GB) — the HF card's performance table matches paper Table 8 to the last digit.

5itm_head geometry — the component the loss does not constrain

itm_head is Linear(d, 2) and softmax CE is shift-invariant, so the loss only constrains the difference component wd = w1 − w0 (385 effective out of a nominal 770). The sum component ws = w1 + w0 is left free by the loss and only slowly shaved by weight decay (0.05). Evaluation ranks by z1 (= (wd+ws)·h / 2 + …), so the closer ‖ws‖/‖wd‖ is to 0, the more z1 ranking = gap ranking.

Raw separation is not scale-invariant — the correct metric is within-query d′

separation = mean(match_gap) − mean(distractor_gap) = wd·(hmatch − hdistractor), so it is directly proportional to ‖wd‖. The teacher's ‖wd‖ is 2.7× the student's (3.338 vs 1.233), so a raw comparison is contaminated by head scale. To remove scale entirely, the denominator must be in the same units as gap — d′ = (mean gapcorrect − mean gapdistractor) / std(gapdistractor), measured within a query.
