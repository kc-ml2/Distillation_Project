# 경량 비전-언어 사전학습을 위한 지식 증류 진단

손실별 분석과 ITC, ITM, LM 증류 재설계를 거친 온라인 고유 파라미터 69.4M의 경량 BLIP 학생 모델은 검색과 캡셔닝에서 우수한 성능을 달성합니다.

다음 표는 최종 체크포인트의 COCO Karpathy 검증 지표이며, 모든 캡션 행에 동일한 저장 생성 결과와 COCOEvalCap 채점 프로토콜을 적용했습니다.

| 모델 | 온라인 고유 파라미터 | ITC r_mean | ITM r_mean | CIDEr | SPICE |
|---|---:|---:|---:|---:|---:|
| 소형 학생 기준선 | 69.4M | 63.41 | 70.93 | 1.063 | 0.201 |
| **통합 증류** | **69.4M** | **`{{FINAL_ITC}}`** | **`{{FINAL_ITM}}`** | **`{{FINAL_CIDER}}`** | **`{{FINAL_SPICE}}`** |
| 베이스 용량 모델 | 252.4M | 66.20 | 73.22 | 1.095 | 0.208 |

파라미터 수는 온라인 사전학습 그래프의 고유 파라미터를 세되 공유 가중치는 중복 제거하고, 모멘텀 사본과 큐 버퍼는 제외했습니다.

- 후보 구조 불일치로 인해 단순한 ITC KD가 실패했습니다.
- 이진 ITM 소프트 타깃은 하드 네거티브 판별력을 약화했습니다.
- 손실별 재설계는 검색과 캡션 지표 여덟 개 모두를 개선했습니다.

## 단순한 증류가 실패한 이유

| 손실 | 관찰 | 진단 또는 가설 | 최종 구성 | 결과 |
|---|---|---|---|---|
| ITC | 배치 내 교사 타깃이 큐 기반 학생 목적함수에서 실패함 | 형상 정렬만으로는 후보 집합, 큐 상태 또는 확률 구조가 정렬되지 않음 | 정렬된 교사 큐 + 네이티브 타깃에 확률 수준 혼합 | 검색 성능 향상 |
| ITM | 쌍별 소프트 타깃이 검색 성능을 크게 저해함 | 이진 헤드가 전달하는 관계적 다크 놀리지는 제한적이며, 소프트 타깃은 판별력을 약화함 | 각 포지티브와 상위 k개 하드 네거티브에 대한 하드 라벨 CE + 대조 증류 | 검색 성능 향상 |
| LM | 토큰 KD가 캡셔닝을 개선함 | **가설:** 대규모 어휘 분포는 이진 헤드보다 풍부한 다크 놀리지를 전달함 | 시프트 정렬, 패딩 마스킹된 `T^2` 스케일링 Hinton KD | 캡션 지표 여덟 개 모두 향상 |

### ITC: 형상 일치만으로는 충분하지 않음

| 교사 타깃 | 후보 구조 | ITC r_mean |
|---|---|---:|
| 학생 기준선 | 네이티브 모멘텀 큐 | 63.41 |
| 배치 내 교사 + 제로 패딩 | 형상만 정렬됨 | 57.64 |
| 교사 큐 | 후보 공간이 완전히 정렬됨 | 64.49 |

제로 패딩은 타깃 너비를 맞췄지만 후보의 의미까지 맞추지는 못했습니다. 텐서 형상 일치만으로는 충분하지 않았습니다. 효과적인 증류를 위해서는 교사와 학생이 동일한 후보 집합, 큐 상태, 확률 구조를 공유해야 했습니다.

### ITM: 이진 타깃이 아닌 대조 구조를 증류

| ITM 감독 | ITC r_mean | ITM r_mean |
|---|---:|---:|
| 하드 라벨 기준선 | 63.41 | 70.93 |
| 쌍별 소프트 타깃 | 64.37 | 63.51 |
| 하드 CE + 상위 k 대조 증류 | 64.87 | 71.60 |

쿼리 내 진단은 쌍별 소프트 타깃이 랭킹 마진을 압축하고 검색 성능을 저해했음을 보여줍니다. 하드 라벨 ITM 분류를 유지하면서 각 포지티브와 상위 k개 하드 네거티브에 대한 대조 증류 손실을 추가했습니다.

### LM: 대규모 출력 공간이 더 나은 증류 타깃

다음 절제 실험은 최종 체크포인트의 COCO Karpathy 테스트 생성 결과를 SPICE를 포함한 동일 COCOEvalCap 프로토콜로 채점했습니다.

| 지표 | 학생 기준선 | LM 증류 | 절대 변화량 |
|---|---:|---:|---:|
| BLEU-1 | 0.7350 | 0.7444 | +0.0094 |
| BLEU-2 | 0.5705 | 0.5811 | +0.0105 |
| BLEU-3 | 0.4334 | 0.4425 | +0.0090 |
| BLEU-4 | 0.3267 | 0.3343 | +0.0076 |
| METEOR | 0.2719 | 0.2738 | +0.0019 |
| ROUGE-L | 0.5538 | 0.5577 | +0.0039 |
| CIDEr | 1.0764 | 1.1028 | +0.0263 |
| SPICE | 0.2029 | 0.2067 | +0.0038 |

LM 목적함수는 시프트 예측 정렬, 패딩 마스크, 표준 `T^2` 스케일링을 적용해 약 30K개 어휘 로짓을 증류합니다. **가설:** 이 대규모 어휘 분포가 이진 헤드보다 풍부한 다크 놀리지를 전달하기 때문에 토큰 KD가 캡션 지표 여덟 개 모두를 개선한 것으로 보입니다.

## 통합 목적함수

$$
\mathcal{L}_{\mathrm{total}}
=
\mathcal{L}_{\mathrm{ITC}}^{\mathrm{mixed\ target}}
+
\mathcal{L}_{\mathrm{ITM}}^{\mathrm{hard\ CE}}
+
\lambda_{\mathrm{ITM}}\mathcal{L}_{\mathrm{ITM}}^{\mathrm{contrastive\ KD}}
+
\mathcal{L}_{\mathrm{LM}}^{\mathrm{CE}}
+
\lambda_{\mathrm{LM}}\mathcal{L}_{\mathrm{LM}}^{\mathrm{token\ KD}}.
$$

- ITC는 정렬된 교사 확률을 학생의 네이티브 큐 기반 타깃에 혼합합니다.
- ITM은 하드 라벨 CE를 유지하면서 각 포지티브와 상위 k개 하드 네거티브에 대한 대조 증류를 추가합니다.
- LM은 `T^2` 스케일링을 적용해 어휘 분포에 대해 시프트 정렬되고 패딩 마스킹된 토큰 KD를 수행합니다.

## 한계

- 모든 이미지-텍스트 쌍에 패치 및 토큰 상태에 대한 교차 어텐션이 필요하므로 ITM 후보 스케일링은 메모리 제약을 받습니다. 이러한 상태는 ITC 특징처럼 간결하게 큐에 저장할 수 없습니다.
- 전체 `B x B` 평가는 `B=40`일 때 `3B`개 쌍에 대한 네이티브 순전파의 약 13배에 해당합니다. 상위 k는 선형적인 후보 비용을 제한하지만 제거하지는 못합니다. 하드 라벨 CE는 안정적인 네이티브 분리 앵커로 유지됩니다. CE 자체를 상위 k로 확장하면 통제된 목적함수가 달라지고 메모리 사용량도 더 늘어납니다.

## 결론

1. 교사 신호를 단순히 출력 형상이 아니라 학생의 네이티브 목적함수 구조에 맞춰야 합니다.
2. 어휘와 같은 대규모 출력 공간은 이진 헤드보다 풍부한 다크 놀리지를 제공하는 것으로 보입니다.
3. 소프트 타깃이 판별력을 약화할 때는 강력한 하드 감독을 유지해야 합니다.
4. 통합 모델은 경량 학생 모델의 성능을 개선하며 검색과 캡셔닝 전반에서 베이스 용량 모델에 근접합니다.
